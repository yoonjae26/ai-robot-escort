# 지켜줄개 · 안심동행

카카오 지도 연동을 지원하는 Flutter 안심동행 앱입니다.

## 카카오 지도 설정

카카오디벨로퍼스에서 앱을 만들고 **카카오맵 사용 설정을 ON**으로 변경합니다.

- Android: 패키지명 `com.example.jikyeojulgae`와 디버그·릴리스 키 해시를 네이티브 앱 키에 등록합니다.
- iOS: Runner의 Bundle ID를 네이티브 앱 키에 등록합니다.
- Web: 실행할 도메인(로컬 개발 시 포트 포함)을 JavaScript 키에 등록합니다.

키는 저장소에 기록하지 않고 실행 시 전달합니다.

```sh
flutter run --dart-define=KAKAO_NATIVE_APP_KEY=네이티브앱키
flutter run -d chrome --web-port 8080 --dart-define=KAKAO_JAVASCRIPT_APP_KEY=자바스크립트키
```

키가 없거나 지도 인증에 실패하면 앱은 자동으로 내장 지도를 표시합니다.

## 레퍼런스 분석 및 적용

- 레이아웃: 브랜드, 큰 제목, 지도/상태 카드, 주요 행동 버튼 순서. 홈에는 3개 탭을 배치했습니다.
- 색상: 딥 네이비 #0B2540 중심의 배경과 카드, 선명한 민트 #18CDB5 강조, 도움 요청 레드 #FF3F58.
- 카드: 네이비 반투명 표면에 블러 18, 흰색 하이라이트 테두리와 내부 반사광을 더해 Apple Jelly 분위기를 표현합니다.
- 버튼: 최소 58px 높이. 민트 젤리 기본 행동, 네이비 젤리 보조 행동, 코랄 젤리 도움 요청으로 구분합니다.
- 타이포그래피: 29px 굵은 제목, 14~16px 본문, 10~12px 보조 정보. 시스템 한글 글꼴을 사용합니다.
- 여백: 화면 좌우 24px, 카드 내부 18px, 주요 영역 사이 16~24px.
- 지도와 Hero: 카카오 지도 위에 민트 경로와 실시간 동행 위치를 표시합니다. 연결할 수 없으면 twilight 내장 지도로 전환됩니다.
- 원본 이미지를 잘라 쓰지 않고, 저녁 공원과 로봇을 자체 벡터 드로잉으로 구성했습니다.
- 모바일 중심의 최대 480px 레이아웃과 스크롤을 적용했습니다.

## 체험 흐름

출발지·목적지 선택 → 경로 확인 → 카메라 자동 인식 → 동행 시작 → 일시 정지/재개 → 도착 → 평가 → 이용 내역.

도움 요청/취소, 종료 확인, 홈/이용 내역/내 정보 탭을 지원합니다. 위치 이동과 카메라 인식은 현재 UI용 모의 데이터이며 완료한 동행과 평가는 메모리에만 저장해 재실행하면 초기화됩니다.

## 구성과 검증

- lib/main.dart: 진입점 및 앱 테마
- lib/ui/prototype.dart: 화면과 데모 상태 전환
- lib/ui/kakao_route_map.dart: 카카오 지도와 경로 오버레이
- lib/ui/scene.dart: 연결 실패 시 지도와 로봇 일러스트
- test/widget_test.dart: 주요 동행 흐름, 작은 화면, 위치 선택 검사

```sh
flutter analyze
flutter test
flutter build web
```

검증 결과: Dart 정적 분석 오류 없음, 위젯 테스트 2개 통과, 웹 릴리스 빌드 성공.
이 Windows 환경에서는 Flutter 분석 서버와 테스트 엔진이 한글 경로에서 실패해,
분석은 SDK의 `dart.exe analyze lib test`로 실행했습니다. 테스트는 임시 영문
드라이브 별칭과 프로젝트 내부 TEMP/TMP 경로를 사용해 통과했습니다.
